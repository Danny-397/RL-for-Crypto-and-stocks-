## What changed because of these results

- **The PPO.** Seven implementation details, together, make it match SB3 on
  InvertedPendulum, Hopper and HalfCheetah (`repaired_ppo()`). Pendulum is
  unexplained. Defaults are unchanged so the published numbers still reproduce.
- **The crypto split.** Per-coin cuts leak across coins in calendar time.
  `load_real_basket(..., split="common")` cuts every coin on one date. Published
  crypto numbers are labelled as affected in RESULTS.md, the README, the paper and
  the site.
- **The conclusion.** Unchanged: across implementations, algorithms, budgets,
  splits and universes, no agent beats buy-and-hold, and on stocks every one is
  significantly worse.

## Deviations from the registration

- E2–E4 used seeds 200–209 as registered. E1 used seeds 0–9 as registered.
- The registration did not anticipate either diagnosis round, the calendar leak
  or the repaired PPO; each was added by a dated amendment before its run.
- The data were committed encrypted (`data/encrypted/`) so the runners could use
  the archived snapshot; the key is a repository secret. The decrypted files were
  checked against the registered snapshot before every run.
